# خبير الفوركس أنور بدران | Anwar Badran Forex Expert

موقع ثابت ثنائي اللغة (العربية افتراضيًا والإنجليزية اختيارية) لعرض البرامج والمؤشرات وأدوات التداول المجانية، جاهز للنشر على GitHub Pages.

## محتويات المشروع
- `index.html`: الصفحة الرئيسية.
- `products.html`: معرض المنتجات مع البحث والفلاتر.
- `product.html`: صفحة تفاصيل ديناميكية لكل منتج.
- `categories.html`, `about.html`, `contact.html`: صفحات إضافية.
- `data/products.json`: بيانات المنتجات.
- `assets/css/style.css`: التصميم المتجاوب.
- `assets/js/app.js`: اللغة والبحث وعرض المنتجات.
- `assets/images/`: الشعار وصور SVG أصلية تجريبية للمنتجات.

## مهم قبل النشر
المنتجات الموجودة حاليًا هي أمثلة/بطاقات أولية لعرض شكل الموقع. **روابط التنزيل غير مضبوطة افتراضيًا**؛ يجب ربط كل بطاقة بملف حقيقي تملك حق توزيعه قبل نشر الموقع للزوار. لا ترفع ملفات EX4/EX5 أو برامج طرف ثالث إلا إذا كان لديك حق توزيعها.

## إضافة رابط تنزيل مباشر من GitHub Releases
1. أنشئ مستودعًا عامًا على GitHub وارفع ملفات الموقع.
2. أنشئ Release في المستودع وارفع ملف المنتج مثل `RocketOneSignals.ex5` أو ملف ZIP.
3. افتح `data/products.json`.
4. ابحث عن المنتج المطلوب، ثم ضع رابط الملف الكامل في الخاصية `downloadUrl`. مثال:
   `"downloadUrl": "https://github.com/USERNAME/REPOSITORY/releases/download/v1.0/RocketOneSignals.ex5"`
5. ارفع التعديل إلى GitHub. سيظهر زر التحميل مفعّلًا للمنتج.

رابط GitHub Release المباشر ينزل الملف عادةً من صفحة الموقع مباشرة إلى مجلد التنزيلات الافتراضي للمتصفح. إعدادات المتصفح قد تعرض نافذة اختيار مكان الحفظ، ولا يمكن لموقع ويب فرض مجلد Downloads على جميع المتصفحات.

## إضافة منتج جديد
انسخ كائن منتج في `data/products.json` وعدّل:
- `id`: معرّف فريد باللغة الإنجليزية وبدون مسافات.
- `name` و`description`: النص العربي.
- `nameEn` و`descriptionEn`: النص الإنجليزي (اختياري لكنه مستحسن).
- `category`: أحد المعرفات الموجودة في `assets/js/app.js`: `mt4`, `mt5`, `mt4mt5`, `ea`, `windows`, `trading-tools`, `utilities`, `other`.
- `version`, `updated`, `platform`, `image`, `downloadUrl`, `fileName`.
- `features` و`featuresEn` و`requirements` و`requirementsEn`.

ضع صور المنتجات في `assets/images/products/` واستخدم مسارها في `image`. تذكر أن هذه الصفحة الثابتة لا تحتاج قاعدة بيانات أو خادم.

## تخصيص إعدادات الموقع
افتح `assets/js/app.js` وعدّل كائن `SITE` لتغيير رابط المستودع وإضافة وسائل التواصل. حدّث نصوص التواصل في `contact.html` حسب معلوماتك.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **محتويات مجلد المشروع** إلى جذر المستودع (بحيث يكون `index.html` في الجذر).
3. من `Settings` ثم `Pages` اختر `Deploy from a branch`.
4. اختر الفرع `main` والمجلد `/(root)` ثم احفظ.
5. انتظر اكتمال النشر وافتح رابط GitHub Pages الذي يظهر في إعدادات Pages.

> اختبر الموقع بعد النشر، لأن تحميل ملف JSON يعمل عبر HTTP/HTTPS. لا تفتح `index.html` بالنقر المزدوج من جهازك وتتوقع عمل بيانات المنتجات؛ شغّله من GitHub Pages أو خادم محلي.

## ملاحظات
- الموقع لا يحتاج إلى حسابات مستخدمين أو قاعدة بيانات.
- لا يحتوي على نموذج تواصل وهمي؛ أضف خدمة إرسال حقيقية إذا أردت نموذجًا يرسل رسائل.
- الموقع لا يضمن أمان الملفات المرفوعة تلقائيًا؛ افحص الملفات وتأكد من سلامتها قبل توزيعها.
- لا توجد رسوم على استضافة صفحات الموقع عبر GitHub Pages ضمن حدود وشروط GitHub الحالية.
